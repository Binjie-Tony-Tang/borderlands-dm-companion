# Local translations

This directory intentionally contains no translated source books or card catalogs.
The application can load a local `catalog.zh-Hans.json` and the optional
`private-rules.zh-Hans.json` described in [the private-content interface](../docs/private-content-interface.md).
Translations retain the rights and provenance requirements of their source material.
A translation is not permission to republish a commercial book or card set.

Keep personal catalogs untracked. `.gitignore` excludes their JSON files.
